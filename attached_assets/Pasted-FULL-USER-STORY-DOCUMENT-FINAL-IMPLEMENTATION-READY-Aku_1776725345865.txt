Akure Airport Staff Cooperative Multipurpose Society Web ApplicationPRODUCT GOAL
To develop a secure, role-based web application that manages cooperative operations including member accounts, savings, loan processing, and cooperative store transactions with full transparency, auditability, and controlled financial workflows.

USER ROLES
1. Super Admin
Full system control
Final authority on loan approvals
Manages roles, permissions, and system configurations
Access to full audit logs

2. Admin
Handles daily operations
Manages members, store items, and Excel uploads
Reviews and approves loan applications (first stage)

3. Financial Auditor
Validates financial records
Reviews loan applications after Admin approval
Confirms or flags loan applications before final approval
Audits all financial transactions
Generates audit and compliance reports
Limited edit rights (validation only, no transaction creation)

4. Treasurer
Monitors loan lifecycle across all stages
Disburses loans after Super Admin approval
Marks loan status as Disbursed
Oversees fund allocation and reconciliation
Supports financial reporting

5. Member
Views personal financial data
Applies for loans
Purchases store items
Tracks savings, loans, and repayments

AUTHENTICATION & SECURITY
As a User, I want to log in using my email and password so that I can access my account securely.
As a User, I want to receive an OTP via email during login so that my account is protected.
As a System, I must enforce OTP verification before granting access.
As a System, I must log all activities (logins, approvals, transactions) for audit purposes.
